# 场区底图与区域绘制操作说明

v1.2增加管理员自定义底图和图上区域编辑。员工、负责人仍按原有权限查看位置和轨迹，只有管理员可以更改底图与区域。

## 上传底图

1. 启动系统并以管理员登录，打开左侧“地图与区域”。窄屏先点左上角菜单。
2. 在“1 上传底图与设置比例”选择PNG或JPG文件。单文件最大5MB，宽高均为16—4096像素。图片在本机校验、去除元数据并规范化为PNG，不上传地图云服务。
3. 填写名称、整张图片宽度对应的实际距离，以及图片左下角在场区米制坐标中的x、y。图片保持原始宽高比；x向右，y向上。
4. 填写调整原因，点击“保存底图配置”。以后不选新文件，也可以调整当前图片的比例和位置。多人同时修改时，过期配置会被拒绝，需要刷新后重做。

“图片完整宽度”包括图片的留白与边框，不是某两个建筑物之间的距离。图片应无明显透视畸变，已有区域与历史位置所使用的场区坐标系应保持一致。换图不会自动移动区域或历史坐标；需要对齐实际图纸和测量条件。

项目附有`evidence/simulated/site-map-demo-v1/site-plan-demo.png`，仅供软件演示：1200×480像素，完整宽度600米，左下角x=-40、y=-60。图上明确标注模拟，不代表真实矿厂布局。可以用它练习上传与绘制；正式场区应换成自己的图纸并实测。

## 绘制新区域

1. 在“2 在图上绘制或编辑区域”选择“新建区域”，填写名称，选择“作业区”或“受限区”。
2. 点击“开始绘制”，回到上方地图，按边界顺序依次点击拐点。至少3个、最多100个顶点。
3. 点击“完成绘制”。编号顶点可以直接拖动；“撤销末点”“清空草稿”和“删除选中顶点”用于整理当前草稿。
4. 填写原因，点击“保存区域边界”。服务端拒绝自相交、重复、面积过小或坐标无效的多边形；失败时保留草稿供修改。

编辑已有区域时，从下拉框或区域列表选择它，拖动编号顶点后保存。已有区域的名称和类别保持不变，本入口更新其边界。已有的“基础管理→填写坐标更新边界”仍可使用。

保存操作立即生成区域新版本。过去的记录和后来补传的记录继续按各自观测发生时的版本判断。作业区的新建不会自动给员工分配作业区，仍由负责人按原流程分配。受限区保存后参与后续观测的提示性判断。

## 对齐手机定位

“3 手机定位与底图对齐”沿用系统原有局部标定：在图上选择经纬度已知的基准点，填写实测经纬度及旋转角，再保存。平面x、y可通过“在图上选择已知点”填写。

上传图片本身不会自动获得真实经纬度。手机仍需可信HTTPS、定位授权和前台运行。标定影响后续采集，已有观测不会追溯改写。真实手机与场地对齐尚需用户实测，浏览器模拟演示不能替代。

## 监控与历史回放

“现场总览”使用当前已保存的底图，继续显示位置来源、最近时间和不确定度。上报或配置变化通过原有SSE通知刷新；位置缺口仍不插值。

“轨迹回放”默认“使用当前底图”，便于把已有轨迹放到当前图纸上查看。选择“按回放时间选版本”时，底图随回放时刻匹配当时版本；早于首次上传的时段使用内置示意图。两种模式下，区域边界都按回放时刻匹配历史版本。

## 数据与交付

图片保存在SQLite的`site_map_assets`表，比例、位置和生效区间在`site_map_versions`表。管理员“备份并校验恢复”生成的备份包含图片、底图版本和原有业务数据。备份使用独立连接转换为可独立打开的SQLite格式，不改变运行库的WAL模式。

源码包保留原有示意图和模拟示例图，排除正在运行的数据库、用户上传图片、照片和私钥。老师首次启动后可以自行上传图纸；原机器上已保存的图纸随本地数据库保留。
