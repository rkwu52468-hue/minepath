# 公开版本整理说明

本仓库是 MinePath 当前系统源码的可演示快照。原毕业设计目录和本地 Git 历史保留，公开仓库单独建立，不上传旧历史中的论文资料和本机配置。

包含应用源码、依赖清单、测试及冻结响应契约、确定性模拟数据生成脚本、使用与设计文档、两张明确标注模拟数据的界面截图。

排除论文/开题报告/学校模板、参考文献 PDF、真实位置、运行数据库、照片、备份、TLS 证书和私钥、会话签名密钥、账号令牌、虚拟环境、工具缓存及旧交付压缩包。

为可移植性调整 Windows 启动脚本为项目相对路径；测试 Node.js 通过 PATH 或 MINEPATH_NODE 查找；实验脚本临时目录移入当前项目 .cache。原业务校验与冻结测试断言不改松。

本次上传范围中的巡检代码为原目录已有工作文件，保留并加入当前回归验证。历史截图来自 v1.2，不宣称已覆盖所有后续功能界面。

默认演示账号与密码属于代码内的虚构种子数据，不是个人 GitHub 凭据。真实运行文件必须继续保留在 .gitignore 排除范围。
