# 操作说明

## 先演示，再实测

双击根目录 `Start-System.cmd`，在电脑浏览器打开 `http://127.0.0.1:8080`，使用README中的账号。窄屏左上角展开导航，宽表格可横向滚动；对话框内容可上下滚动。数据均保存在本机D盘项目的 `data/`。

管理员“现场总览→启动30人模拟流”会启动虚拟采集器，界面位置与数据明确标注“模拟”。E001会周期性进入受限区，用于观察提示及恢复，管理流程仍由使用者操作。停止模拟流结束本轮模拟会话，重启程序也会明确结束遗留模拟采集授权。手机真实测试前先停止模拟，按 MOBILE.md 登记自己的测试端。

## 员工

“我的上报”显示登记码、设备、区域、采集状态、最后实际定位和本机待上传数。首次使用由管理员登记浏览器码；选择已分配作业区和目的后开始。权限被拒绝、定位超时或页面被系统暂停时，按提示处理，不会虚构位置。网络恢复后重试缓存；服务端拒绝的记录保留失败原因，不无限重试。结束请求遇到断网会待服务器确认，**服务器确认时刻才是会话截止时间**，客户端请求时间单独记入审计。

负责人下达转场后，“转场任务→查看与处理→开始转场”明确启动计时。允许绕行，受限区检查持续。到达后申报实际到达时间；负责人确认后区域归属按核实时刻生效。驳回后补充申报，原计时和延期历史保留。

“事件核查”提交本人说明；“求助协同”可不带有效位置发起求助、可选照片。在页面仍打开的情况下，断线求助先存本机，恢复后上传。看到待负责人处理结果后可确认解决或反馈未解决。清除网站数据会丢失尚未上传的本机缓存。

“轨迹回放”只查看本人，查询后播放/暂停、改倍速、拖动时间。长缺口处不放置推算位置。地图点保留来源、不确定度与区域版本。

“消息通知”查看相关任务和处理进度、标记已读；“个人信息”维护本人姓名与密码。

## 班组负责人

现场总览仅显示当前在管员工；历史轨迹按记录发生时的班组授权。调组后新负责人不会获得旧班组整段历史；旧负责人仍可查自己班组时段的数据。

“转场任务”直接下达起终点及允许时长。员工开始后才计时；超时生成待核查事项，任务不自动取消。延期必须给原因。确认到达时区分申报时刻、确认生效时刻和操作时刻；不删除此前提示，按人工结论留痕。取消必须说明原因和下一步，继续移动需另发任务。

事件的“仍在发生/观测已恢复/会话已结束/归属已切换”和“待核查/核查中/已结案”是不同维度。恢复不会自动结案；结案需要说明依据和结论，员工未回复也可根据电话核实等依据处理。两次独立进入区域生成两条事件。

求助接单后由原处理人跟进，员工调组不会自动改变处理人；新组负责人可协助。只有当前处理人可提交处理结果；管理员明确交接后责任改变。旧区外/中断事件继续由原班组现任负责人处理。

“统计报表”生成当前权限范围内的时间快照，可CSV导出。会话跨度按时段并集计算，合格观测覆盖、缺失、模拟/浏览器点数分别列出；不把缺口当连续轨迹，也不把会话当工时。补传不会修改旧快照，需要生成新快照比较。

## 管理员

基础管理包括新增/停启账号、密码重置、逐行CSV员工导入、调组、委派正式/临时负责人、采集端登记换绑、区域多边形版本、值班配置、备份校验。

调组允许在上报期间进行：保留会话，转场任务随员工交接，任务时间不重置；没有负责人的新组也允许调入，管理员应另行委派管理人员。已接求助通过“求助详情→指定/交接处理人”单独交接。

管理员可在“地图与区域”上传底图，直接点击绘制区域并拖动顶点修改；也可在基础管理按边界顺序填写JSON坐标。区域多边形采用局部米制坐标，至少三个顶点。提交时即时生效，旧记录仍用当时版本。规则与标定中可修改演示阈值，任何阈值都需结合真实设备测试确认。

重复性评估分固定点和重复路线。固定点对样本算术中心求距离分位数；路线需独立的参考趟次时段，对有效折线路段求单向最近几何距离。路线形状、覆盖范围、采样条件会影响结果，应人工确认同一路线，不能视作绝对定位误差。

备份按钮生成包含底图图片与配置的数据库及已保存照片的ZIP，并用独立SQLite连接执行完整性/外键检查。它不在线覆盖运行库，不包含会话签名密钥或TLS私钥。恢复正式数据应先停服务，先在新目录恢复并验证，再由管理员选择替换，不在运行过程中直接覆盖。

## 演示建议顺序

管理员开模拟流 → 负责人查看本组 → 下达A到B任务 → 员工开始、申报到达 → 负责人延期/确认或驳回 → 管理员调组检查权限 → 员工发求助 → 原负责人接单与处理 → 员工确认或重开 → 生成报表、查看审计与备份。所有演示账号与位置都保持模拟标注。

底图上传、比例设置、图上区域绘制及历史底图选择的详细步骤见 [MAP_GUIDE.md](MAP_GUIDE.md)。

## 巡检

负责人或管理员在巡检页面选择员工、作业区并指派。员工开始本人任务后，可查看作业区相关情况，填写区域或在岗人员的检查记录；标记发现问题时建立事件供管理人员处理。至少提交一条检查记录后才能完成；管理人员撤回需说明原因。

正在巡检的员工可查看可代处理的本组求助，代接单、填写进展并提交处理结果。求助主责与实际代处理人分别记录，员工确认或反馈未解决的流程保留。
